# SiteMapper

A simple Python web crawler that collects internal links starting from a given URL.

## Installation

Clone the repository:

```bash
git clone https://github.com/etay1272/SiteMapper.git
cd SiteMapper 

Install dependencies: 
```bash 
uv sync 
``` 

## Usage

Create a .env file based on the example: 
```bash
cp .env.example .env 

Run the crawler:
uv run main.py 
```
